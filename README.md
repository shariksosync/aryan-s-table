# Aryan’s Table

# PROJECT: ARYAN'S FAMILY RESTAURANT & BAR – COMPLETE FOOD DELIVERY E-COMMERCE WEBSITE WITH ADMIN PANEL

Build a complete, premium, modern, visually impressive and fully responsive food ordering and delivery e-commerce website for **Aryan's Family Restaurant & Bar**.

The project must include:

1. A complete customer-facing restaurant website.
2. A functional food menu and product catalog.
3. A complete shopping cart and checkout experience.
4. Customer account and order history functionality.
5. A comprehensive admin dashboard.
6. Admin-controlled website content and image management.
7. Original restaurant image reuse and AI-generated images where required.

The final result should look like a professionally designed restaurant ordering platform with a premium hospitality identity, not a generic food delivery template.

---

# 1. STRICT TECHNOLOGY REQUIREMENTS

Use ONLY the following technologies:

- React.js
- Vite
- Tailwind CSS
- JavaScript
- React built-in hooks: useState, useEffect, useContext and useReducer where required.
- Browser localStorage for frontend data persistence.

### Strict restrictions

DO NOT use:

- Next.js
- TypeScript
- Bootstrap
- Material UI
- Shadcn UI
- External component libraries
- External icon libraries
- React Router or any other routing library
- Firebase
- Supabase
- MongoDB
- Any other database
- Any backend
- External API integrations
- Any additional frameworks or unnecessary dependencies

Use inline SVG icons or CSS-created icons.

Use JavaScript mock data for all website content.

This is a frontend-only demonstration project. All customer interactions, admin functionality, authentication and data management must work using React state and browser localStorage.

### Important implementation requirements

- Use reusable React components.
- Use a shared React Context for global application state.
- Keep product, category, cart, order, customer, coupon and website settings data organized.
- Persist relevant information in localStorage.
- Load saved information when the application starts.
- Ensure admin modifications immediately reflect on the customer-facing website.
- Do not create decorative controls that do nothing.
- Do not leave unfinished pages or placeholder sections.
